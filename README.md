# Factory Requirement & Purchase Management System

## Project Overview
A business process management system developed using Google Sheets and Google Apps Script to streamline factory requirement tracking and purchase-related workflows at Manufacto India.

## Objectives
- Digitize factory requirement management.
- Organize purchase-related information.
- Reduce manual spreadsheet operations.
- Improve data visibility and tracking.

## Technologies Used
- Google Sheets
- Google Apps Script
- JavaScript

## Key Features
- Centralized factory requirement management.
- Automated spreadsheet operations using Google Apps Script.
- Structured purchase tracking.
- Organized data management and reporting.

## Project Type
Business Process Automation | Data Management | Workflow Automation
